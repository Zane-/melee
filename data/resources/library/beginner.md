# Beginner

Information for beginners. Start here if you are just learning the game.

Links collected by The Melee Library. Titles, authors and descriptions are theirs; videos and forum threads are pointers, not content an agent can read here.

| Resource | Author | About |
|-|-|-|
| [The COMPLETE Beginners' Guide to Super Smash Bros. Melee](https://www.youtube.com/watch?v=C16e4E9Mezw) | SSBM Tutorials | They discuss what hardware you need to start playing, how to get acquainted with your local scene, and how to get started on learning the game. |
| [List of Basic Terms](http://smashboards.com/threads/wavedashing-l-cancelling-all-the-terms-read-first-update-12-23-2007.42749/) | AlphaZealot | A list of common jargon used by smashers. The post is pretty old. |
| [Guide to Getting Good at Melee](http://www.reddit.com/r/SSBM/comments/2jc3gb/nmws_guide_to_getting_good_at_melee/) | NMW | NMW explains a stratified way to progress in Melee. Those strata are techskill, punish game, DI, neutral game, and innovation. It provides a general roadmap you can use to look forward on your journey to goddom. |
| [SSBM Competitive Beginner Guide](https://docs.google.com/document/d/1_6o5NHvI9P8-qHp2M8w1gDzL_-JNonEE81Mh4ulY1PY/edit) | SleepyK | SleepyK tells beginners what they need to learn first. His guide emphasizes tech skill, but provides other good teachings, too. |
| [Advanced How to Play](https://www.youtube.com/watch?v=vckV2MJgBzo) | Wak | Teaches basic advanced techniques everyone needs to know. |
| [Drastic Improvement](http://smashboards.com/threads/drastic-improvement.311129/) | UmbreonMow | THE source for having a mindset to improve and how to achieve it. |
| [Improved Drastic Improvement](https://alexspuffstuff.blogspot.com/p/improved-drastic-improvement.html) | alexspuffstuff | Alex criticizes Drastic Improvement's teaching methods and provides an alternative. |
| [How To Learn Melee](https://www.youtube.com/playlist?list=PLoU3TQBakHOrE9yYdNlsmG74LEB0Mf3h8) | Kira | A playlist of videos covering basic techniques. It is a little redundant compared to the previous sources, but maybe you prefer videos. |
| [Basic Tech Skill Guide](http://smashboards.com/threads/basic-tech-skill-guide.342302/) | Mookie Rah | List of some basic tech that every beginner should learn how to do, plus some tips for practicing. Most info is redundant with previous beginner sources. |
| [How to Pick a Character](https://www.youtube.com/watch?v=AGHGEttNjyo) | Core-A Gaming | This video covers the process of finding a main in a fighting game in general. In short, make sure that the character you choose fits your playstyle and don't base everything around perceived strength. |
| [How To Play a Tournament Set](https://www.youtube.com/watch?v=YePIBypk_DI) | Kira | Kira explains the procedure for choosing character, ports, and stages in tournament. |
| [Armada's 5 Tips for Beginners](https://www.youtube.com/watch?v=NQPTlCJ02iA) | Armada | Armada, the best player in the world at the time of posting this, gives the following advice to new players: stick to one character, be open-minded, work on movement, analyze your own matches, and play to learn not to win. |
