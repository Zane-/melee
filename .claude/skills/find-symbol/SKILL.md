# Find a symbol

About half of the decomp's functions are named after their address, so most lookups go through
`config/GALE01/symbols.txt`, the source of truth for address ↔ name.

## From an address (e.g. a Gecko code "inject at 8006B7F4")

```sh
python tools/mex_symbols.py 0x8006B7F4
```

Output gives the containing function and the offset inside it (`Fighter_procInput +0xAE4`).
Then:

1. `grep -rn "Fighter_procInput" src --include=*.c | head` to find the definition.
2. To find the exact statement for an offset, open the original's split assembly
   `build/GALE01/asm/<same path as the .c>.s` (generated by the first `ninja`), find
   `.fn <name>`, and read the instructions around the address. Match them to the C by the calls
   and struct offsets nearby.

Without the tool: the entry in `symbols.txt` with the largest address ≤ yours whose
`size:` covers it.

## From a MexTK / Training Mode name

```sh
python tools/mex_symbols.py Fighter_GetGObj Text_SetText --headers
```

- `docs/ai/tm-symbol-map.tsv` has every vanilla function TM-CE's C code uses, pre-resolved.
- A result of `?` or `(inside)` a data symbol means the name is m-ex's own injected code
  (`calloc`, `MEX_LoadRelArchive`), not a vanilla function. It has no native equivalent; replace
  the use.
- Globals written as `static T* stc_x = 0x80…` in `MexTK/include/*.h`: look the address up the
  same way; the result is a `.bss` / `.data` / `.sdata` symbol.
- `r13`-relative globals (`R13_OFFSET(-0x514C)`): the small-data base is `0x804DB6A0`, so the
  address is `0x804DB6A0 + offset`. Look that up.

## From behaviour ("where is hitlag decremented?")

1. Start from the module (`docs/ai/codebase-map.md`) and the per-frame proc list in
   `Fighter_Create` (`src/melee/ft/fighter.c`) or the scene callbacks in `gm/gmscdata.c`.
2. Grep named fields and enums rather than function names: struct fields are better named than
   functions (`hitlag`, `ftCo_MS_`, `percent`).
3. Follow callers: `grep -rn "name(" src`.
4. Community names help: TM-CE's `GTME01.map` (`../TrainingMode/GTME01.map`) names ~6,700
   addresses. `grep -i "hitlag" ../TrainingMode/GTME01.map`, then look the address up here.

## Cautions

- Header comments like `/* 1A4510 */` can be stale. Trust `symbols.txt`.
- Several static functions share a name across files (`onEnterVs` exists in more than one game
  mode). Use the address to pick the right file: `config/GALE01/splits.txt` maps address ranges
  to files.
- Names change upstream. If a documented name does not grep, look it up by address.
- Do not rename vanilla symbols as part of mod work; renames are separate upstream-style changes.
